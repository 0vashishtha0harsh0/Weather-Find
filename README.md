# Weather App 🌤️

Search any city and instantly get real-time weather data.

## Features
- Real-time weather data
- Temperature, Humidity, Weather Condition
- Clean dark theme UI

## Tech Used
- HTML, CSS, Vanilla JavaScript
- wttr.in Weather API (Fetch API)

## How to Use
1. Open index.html in browser
2. Type any city name
3. Click Find
